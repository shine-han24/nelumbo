# nelumbo

책 발췌 조판기. 문장을 붙여넣으면 책의 한 페이지로 조판해 이미지·PDF로 내보냅니다.

## 실행

```bash
npm install
npm run fonts   # 최초 1회 — 한글 웹폰트 내려받기 (약 21MB)
npm run dev
```

`npm run fonts`는 `public/fonts/`를 만듭니다. 이 폴더가 없으면 폰트가 폴백으로
렌더되고 내보내기 결과가 화면과 달라집니다.

## 구조

```
src/
  editor/      Tiptap 에디터, 붙여넣기 정리, 스마트 타이포그래피, 맞춤법 밑줄
  layout/      판형·폰트 정의, 줄 박스 측정, 페이지 분할 엔진
  preview/     페이지 렌더, 배경 레이어, 미리보기 창
  panels/      우측 속성 패널
  theme/       조판 프리셋, 사용자 테마 저장
  export/      PNG/ZIP/PDF 내보내기, 폰트 서브셋 임베딩
  spell/       맞춤법 공급자 인터페이스와 어댑터
api/
  spellcheck.ts   Vercel 서버리스 프록시 (키 은닉 + 레이트리밋)
```

## 알아둘 것

### 페이지 분할

`layout/paginate.ts`가 이 앱의 핵심입니다. CSS `columns`에 맡기지 않고
`Range.getClientRects()`로 줄 박스를 직접 측정해 나눕니다. 그래야 단 수,
고아/과부 줄, 페이지별 배경을 정확히 제어할 수 있습니다.

세 가지를 건드릴 때는 주의하세요.

- **웹폰트 로딩** — 측정 전에 `ensureFontLoaded()`를 반드시 기다립니다.
  폴백 폰트로 재면 모든 페이지 분할이 어긋나고, 새로고침 직후에만 재현되는
  버그가 됩니다.
- **본문 상자 계산** — 미리보기와 페이지네이션이 둘 다 `bodyBox()`를 씁니다.
  한쪽만 하단 표기 높이를 빼면 페이지마다 마지막 줄이 조용히 잘립니다.
- **논리 마진** — 세로쓰기에서 블록은 오른쪽에서 왼쪽으로 쌓입니다.
  `margin-top`이 아니라 `margin-block-start`를 써야 합니다.

### 테마 3계층

- `--ui-*` : 편집 화면 색 (`data-ui-theme`). 기본 톤은 검정·흰색·하늘색·파랑.
  기본 테마 이름은 **운하(雲荷)**, 그 외 운하 밤 / 하늘 / 먹.
- `--paper-*` : 결과물 색 (styleStore가 인라인으로 주입). 종이색 기본값은 `#ffffff`.
- 사용자 테마 : 조판 설정 스냅샷을 IndexedDB에 저장

**미리보기 DOM은 `--ui-*`를 절대 참조하지 않습니다.** 앱을 어둡게 바꿨다고
내보낸 이미지 색이 달라지면 안 되기 때문입니다.

화면 테마는 사용자가 직접 만들 수도 있습니다(`theme/uiCustom.ts`). 기준색
다섯 가지만 받고 나머지 토큰은 계산합니다. 직접 만든 테마는 `:root`에 인라인
변수로 박히므로, **다른 테마로 돌아갈 때 반드시 지워야** 합니다 — 안 지우면
인라인이 계속 이겨서 테마가 바뀌지 않습니다.

### 아이콘

`ui/icons.tsx`의 자체 SVG 세트를 씁니다(검·장검·권총·단검·탄환·칼·트럭·노을
·새벽·연꽃·지팡이·게임패드). 좌측 설정 탭과 브랜드 마크에만 쓰고, 굵게·기울임
같은 서식 버튼은 lucide 아이콘을 유지합니다 — 그 자리까지 검으로 바꾸면
무슨 버튼인지 알아볼 수 없습니다.

### 미리보기 확대·축소

휠은 배율, 드래그는 이동입니다. 기준점(커서 아래 지점)을 정확히 고정하려면
두 가지가 지켜져야 합니다.

- 페이지마다 `transform`을 걸지 않고 **전체를 한 번에** scale합니다. 간격·여백까지
  그 안에 넣어야 콘텐츠 좌표가 배율에 정비례합니다.
- 콘텐츠 둘레에 **뷰포트 한 개 분량의 여백**을 깝니다. 가운데 정렬로 위치를
  잡으면 그 거리가 배율에 따라 변해서 확대할 때마다 화면이 옆으로 흐릅니다.
  여백이 뷰포트보다 작으면 필요한 스크롤 위치가 범위를 벗어나 잘리고, 그 순간 튑니다.

### 내보내기 형식

기본은 **낱장 저장**입니다(`제목-01.png`, `제목-02.png` …). 발췌물은 보통 몇 장이라
ZIP으로 묶으면 압축을 푸는 수고가 더 큽니다. 장수가 많을 때를 위해 ZIP도 남겨 뒀습니다.

### 화면 폭

`useIsNarrow`(900px 기준)로 두 배치를 씁니다. 넓으면 설정·원고·미리보기 세 칸,
좁으면 설정은 서랍으로 넣고 「원고 / 미리보기」 버튼으로 전환합니다.
분할 비율은 **설정 패널을 뺀 나머지** 기준입니다 — 전체 폭 기준으로 잡으면
창이 좁아질수록 미리보기가 먼저 사라집니다.

### 숫자 입력

행간·자간처럼 정확한 값이 필요한 항목은 슬라이더 옆에 직접 입력 칸이 있습니다
(`ui/Control.tsx`의 `Slider`). 슬라이더 범위를 넘는 값도 `hardMin`/`hardMax`
안에서 받아들입니다.

한 가지 주의: 이 행은 `<label>`이 아니라 `role="group"`입니다. `<label>`은 안의
**첫 번째** 컨트롤에만 연결되므로, 슬라이더와 입력칸을 함께 감싸면 숫자 칸을
클릭해도 포커스가 슬라이더로 끌려갑니다.

### 폰트 임베딩

`html-to-image`의 `getFontEmbedCSS`는 쓰지 않습니다. 스타일시트의 `@font-face`를
전부 인라인하는데, 한글 웹폰트는 서브셋이 900개 가까이 되어 20MB를 내려받다
멈춥니다. `export/fontEmbed.ts`가 문서에 실제로 쓰인 (글꼴, 굵기)와 글자의
unicode-range에 해당하는 서브셋만 골라 인라인합니다.

## 맞춤법 검사

현재 **준비 중** 상태입니다. 화면에도 그렇게 표시됩니다.

`SpellProvider` 인터페이스 뒤에 공급자를 갈아 끼웁니다. `PROVIDERS` 배열에 등록된
것만 UI에 나타나고, 쓸 수 있는 공급자가 없으면 패널이 안내 문구로 바뀝니다.

| 공급자 | 상태 |
|---|---|
| `barunhangul` | **정식 API 계약 대기 중** — 유일하게 등록된 공급자 |
| `localRules` | 코드는 있으나 `PROVIDERS`에서 제외 |

`localRules`를 뺀 이유: 형태소 분석 없이 규칙으로만 판단하므로 문맥이 필요한
오류를 놓치는데, 그걸 "맞춤법 검사"로 내놓으면 사용자가 결과를 신뢰해 버립니다.
어설픈 검사기보다 "준비 중"이 정직합니다. 되살리려면 `spellStore.ts`의
`PROVIDERS` 배열에 다시 넣기만 하면 됩니다.

부산대 검사기(`speller.cs.pusan.ac.kr`)는 2024년 10월 서비스가 끝나고
바른한글(`nara-speller.co.kr`)로 이관됐습니다. 비공식 엔드포인트는 공개 배포에
쓸 수 없어 정식 API로 갑니다.

계약이 끝나면 할 일은 두 가지입니다.

1. Vercel 환경변수에 `BARUNHANGUL_API_KEY`, `BARUNHANGUL_ENDPOINT` 등록하고
   빌드 환경변수 `VITE_SPELL_REMOTE=on` 설정
2. `api/spellcheck.ts`의 `callBarunHangul()`에서 요청·응답 형식을 실제 규격으로 교체

프런트엔드는 손댈 필요가 없습니다. 응답 변환 시 `start`/`end`가 **원문의 문자
오프셋**이어야 합니다. 어절 번호나 바이트 오프셋을 준다면 그 함수 안에서
변환하세요. 어긋나면 엉뚱한 자리에 밑줄이 그어집니다.

## 배포

Vercel에 연결하면 `vercel.json` 설정으로 그대로 동작합니다.
`api/spellcheck.ts`가 서버리스 함수로 배포됩니다.

## 보안

### 지금 되어 있는 것

- **XSS** — 미리보기는 `dangerouslySetInnerHTML`을 쓰지만, 넣는 HTML은
  `layout/spansToHtml.ts`가 만든 것뿐입니다. 본문은 `&`·`<`·`>`를 이스케이프해
  **텍스트 노드로만** 들어가고, 태그는 `<strong> <em> <u> <s> <br>` 다섯 개를
  속성 없이 붙입니다. 사용자 입력이 태그나 속성 자리에 닿는 경로가 없습니다.
- **보안 헤더** — `vercel.json`에 CSP, `X-Content-Type-Options`,
  `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, HSTS를 넣었습니다.
  CSP의 `script-src 'self'`가 핵심입니다(빌드 결과에 인라인 스크립트가 없어 가능).
- **API 남용 방지** — `/api/spellcheck`는 POST만 받고, Origin이 우리 호스트인지
  확인하며, 5,000자 상한과 IP당 분당 20회 제한이 있습니다. CORS 헤더를 주지
  않으므로 다른 오리진의 JS는 응답을 읽지 못합니다.
- **비밀 관리** — API 키는 서버리스 함수에서만 읽습니다. `VITE_` 접두사가 붙은
  값은 번들에 그대로 들어가므로 거기에는 비밀을 넣지 않습니다.
- **원고 유출 없음** — 입력한 글과 배경 이미지는 브라우저(IndexedDB)에만 있고
  서버로 보내지 않습니다. 맞춤법 검사만이 유일한 외부 통신입니다.

### 배포 후 확인할 것

1. `/api/spellcheck`에 다른 도메인에서 요청해 403이 나오는지
2. 브라우저 콘솔에 CSP 위반이 찍히지 않는지 — 특히 **내보내기 실행 시**.
   html-to-image가 `data:` SVG와 인라인 폰트를 쓰므로 `img-src data:`와
   `font-src data:`가 필요합니다. 막히면 내보내기가 조용히 실패합니다.
3. 레이트리밋은 서버리스 인스턴스 메모리에 있어 인스턴스가 여러 개면 느슨합니다.
   트래픽이 늘면 Vercel KV나 Upstash로 옮기세요.

### 알아 둘 것

- **자동 저장은 지우지 않습니다.** 공용 컴퓨터에서 쓰면 다음 사람이 이전 원고를
  볼 수 있습니다. 필요하면 "새로 시작" 기능을 추가하세요.
- 발췌한 원문의 저작권은 원저작자에게 있습니다. 이 앱은 그에 대해 아무 권리도
  주지 않습니다.

## 이용 조건

**비상업적 용도로만 사용하세요.** 이 도구와 이 도구로 만든 결과물을 상업적으로
이용하는 것을 금합니다. 이 문구는 앱 좌측 패널 하단에도 상시 표시됩니다.

발췌한 원문의 저작권은 원저작자에게 있습니다. 발췌·인용은 저작권법이 허용하는
범위 안에서만 하시고, 출처 표기 기능(좌측 「출처」 탭)을 사용하세요.

## 폰트 라이선스

`npm run fonts`가 받아오는 것은 전부 OFL 또는 웹 임베딩이 명시적으로 허용된
글꼴입니다 — Noto Serif KR, Noto Sans KR, 나눔명조, 고운바탕, 개구쟁이.
비상업 한정 글꼴(을유1945 등)은 공개 배포 대상이라 넣지 않았습니다.
글꼴을 추가할 때는 `scripts/fetch-fonts.mjs`와 `src/layout/fonts.ts` 양쪽에
등록하고, 라이선스를 먼저 확인하세요.
